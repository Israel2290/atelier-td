# Atelier — Réviser les épreuves

Application statique de révision à partir des épreuves fournies. Les sujets sources sont inclus dans ce dépôt public avec l’autorisation de leur propriétaire.

Ouvrir `index.html` pour accéder à l’application. Elle fonctionne sans compte côté étudiant et sauvegarde la progression dans le navigateur.

Le site est déployé sur GitHub Pages depuis la branche `main`.
